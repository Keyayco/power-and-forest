POWER & FOREST — VANILLA WEBSITE

This folder is a framework-free rebuild of the Power & Forest landscaping website.

Files:
- index.html: semantic page markup and content
- styles.css: responsive design system and layout
- script.js: mobile navigation and quote form interaction
- assets/: local image assets

Open index.html directly in any modern browser or edit it with a basic code editor. No install, build step, or server is required.
